# Amulya R — Personal Portfolio

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `amulya-portfolio` folder.
3. Double-click `index.html` to preview it in your browser.

For best results while editing, open the folder in VS Code and use the Live Server extension.

## Personalise your details
- Replace `assets/amulya-portrait.png` with your preferred portrait (keep the same filename).
- Edit the biography and education text in `index.html`.
- Edit skills and project summaries in `index.html`.
- Add your email, LinkedIn, GitHub, Instagram and resume URL in `js/config.js`.
- Leave unavailable links blank; they will not be displayed.
- Add real certificate cards in the certificates section when you have certificate details.

## Contact form
The form uses a `mailto:` link. Add your real email address to `email` in `js/config.js`. When a visitor submits the form, their email application opens with the message prepared; they must review and send it.

For direct website submissions, connect a form provider such as Formspree and update the submit handler in `js/main.js`. Do not publish a form endpoint until you have configured it.

## Publish
You can deploy this static site using GitHub Pages, Netlify or Vercel. Upload the complete folder contents, keeping the `css`, `js` and `assets` folders in place.

## Notes
Project entries are presented as student concepts/academic work, not as claims of completed commercial products. Add real screenshots, repositories and outcomes as they become available.


## Certificates added
Two Wolfram U PDFs are included in `assets/certificates/`: the Level 1 Certificate in Discrete Mathematics and the Completion Certificate for Introduction to Discrete Mathematics. Their cards appear in the Certificates section and open the original PDF files.
